Only needs Contents: Read and write access on this one repository. See "How do I get a token?" below.

Leave this on for your own computer. Turn it off on a shared or public computer — you'll need to paste the token again next time.

How do I get a token?
  1. Go to github.com/settings/personal-access-tokens/new (sign in to GitHub first).
  2. Give it a name, e.g. "THelectrics admin".
  3. Under Repository access, choose Only select repositories and pick your website's repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else as "No access".
  5. Click Generate token, then copy it — GitHub only shows it once.
  6. Paste it into the box above. You can revoke or regenerate it any time from that same GitHub settings page.
